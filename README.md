# obesity-income
In this project, I explored the relationship between state obesity prevalence and median household income in the United States. Data is from 2022.

I first identified some trends in the data using MySQL. My code can be found in obesity-income.sql and the generated queries are in the queries folder.

Then, I made a few visualizations in Tableau to highlight the correlation between obesity prevalence and median household income. In particular, I included a scatterplot to illustrate the relationship between state obesity prevalence and median household income (identified a correlation coefficient of approximately r = -0.77), a tree map to highlight the contrast in state median household incomes, and a map of the United States colored according to the obesity prevalence of each state. I also added options to filter the dashboard by region, geographical division, state, median household income, and obesity prevalence. My [dashboard](https://public.tableau.com/app/profile/edward.fei/viz/ObesityandWealthInqualityintheU_S_2022/TheRelationshipBetweenObesityandIncomeintheU_S_2022) is posted on Tableau Public.
